== First quest: Enable the Hate, Abuse and Profanity (HAP) detector!

The data scientist team had also gotten the email from Chris at Legal, and have prepared a model for you. 

This model is specifically trained on detecting this type of speech. 

Now, it is time to update the orchestrator and gateway of TrustyAI and introduce the HAP model as a new detector. 

_You press "ConfigMaps" and find "fms-orchestr8-config-nlp" and click it._ 
image:configmap-nlp.png[Configmap NLP]

_You go to "Actions" and then press "Edit ConfigMap"._ 
image:go-to-edit-nlp-config.png[Edit NLP config]

_You copy the following block of code._
[source,bash,role=execute]
----
passthrough_headers:
  - authorization
tls:
  external_llm:
    insecure: true
    cert_path: /dev/null
chunkers:
  sentence:
    type: sentence
    service:
        hostname: chunker-service.gaas.svc.cluster.local
        port: 8085
openai: 
  service:
    hostname: litellm-prod.apps.maas.redhatworkshops.io
    port: 443
    tls: external_llm
detectors:
  regex_competitor:
    type: text_contents
    service:
      hostname: "127.0.0.1"
      port: 8080
    chunker_id: sentence
    default_threshold: 0.5
  prompt_injection:
    type: text_contents
    service:
      hostname: prompt-injection-detector-predictor.gaas.svc.cluster.local
      port: 8000
    chunker_id: sentence
    default_threshold: 0.5
  language_detection:
    type: text_contents
    service:
      hostname: lingua-detector.gaas.svc.cluster.local
      port: 8080
    chunker_id: sentence
    default_threshold: 0.88
  hap:
    type: text_contents
    service:
      hostname: guardrails-detector-ibm-hap-predictor.gaas.svc.cluster.local
      port: 8000
    chunker_id: sentence
    default_threshold: 0.5
----

_You delete the already existing block of text and paste the new full block. Then hit save._
image:add-hap-nlp.png[Add HAP to NLP]

Now it's time to update the gateway so it knows when to apply the new detector. In our case, we want it to look at both input and output.

_You go back to "ConfigMaps", find the "fms-orchestr8-config-gateway" and click it._ 
image:config-gateway.png[Config gateway]

_You press "Actions" and then "Edit ConfigMap"._ 
image:edit-regex.png[Edit Gateway]

_You copy the following block of code._
[source,bash,role=execute]
----
orchestrator:
  host: "localhost"
  port: 8032
detectors:
  - name: regex_competitor
    input: true
    output: true
    detector_params:
      regex:    
        - (?i)\b(orange|apple|nectarine|plum|apricot|banana|grape|melon|pineapple|lime)s?\b
  - name: prompt_injection 
    input: true
    output: false
    detector_params: {}
  - name: language_detection
    input: true
    output: true
    detector_params: {}
  - name: hap 
    input: true
    output: true 
    detector_params: {}
routes:
  - name: all
    detectors:
      - regex_competitor
      - prompt_injection
      - language_detection
      - hap
  - name: passthrough
    detectors:
----

_You delete the already existing block of text and paste the new full block. Then hit save._. 
image:add-hap-gateway.png[Add Lingua to Gateway]


The orchestrator pods will automatically restart themselves. We can have a look to confirm that they are. 

_You press "Pods"._ 
image:pods-restarting.png[Pods restarting]

When it looks like this you know it's time to test out the new detector.
